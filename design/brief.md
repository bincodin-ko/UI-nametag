# UiNametag 메인 창 — 디자인 요약 (2026-10-20)

## 제품
Windows 상주 프로그램. 화면의 부품을 가리키면 "표준 이름 + 소스 코드 위치(파일:줄)"를 알려 주고, 고칠 것을 메모·이동·그리기·녹화로 모아 Claude(AI)에게 MCP로 넘긴다.
지금은 창이 없고 트레이 아이콘(주황 이름표)만 있다. **트레이 아이콘을 누르면 열리는 메인 창**을 만든다.

## 대표 사용자
혼자 앱을 만드는 1인 개발자. 한국어. 디자인 용어를 잘 모름. Claude Code로 코딩. 자기 앱(Windows 앱·Electron·웹사이트)을 고칠 때 씀.

## 메인 창에서 할 일 (흐름)
1. 지금 상태 한눈에: 켜짐/꺼짐, 고르기 모드, 녹화 중 여부, Claude(MCP) 연결 여부, 대기열에 쌓인 고른 것 개수.
2. **내 앱 목록**: 등록된 앱마다 이름, 종류(Windows 앱/Electron/웹사이트), 실행 파일 또는 사이트 주소, 소스 폴더, 사전 항목 수, 마지막 사전 갱신 시각, 상태(정상 / 소스 바뀜 → 다시 만들기 필요 / 폴더 없음).
   - 앱마다: 사전 다시 만들기, 소스 폴더 열기, 지우기.
3. **새 앱 등록** (핵심 흐름, 3단계):
   ① "앱 창 고르기" 버튼 → 화면에서 등록할 앱 창을 클릭 (또는 실행 중인 창 목록에서 고르기, 웹사이트는 주소 입력)
   ② 소스 폴더 고르기 (폴더 선택 + 자동 추천: 최근 프로젝트)
   ③ 사전 만들기 → 진행 표시 → "항목 216개" 결과 + 미리보기 몇 줄 (id → 파일:줄)
4. **대기열**: 고른 것 목록(번호, 앱, 부품 이름, 메모, 동작: 메모/이동/그리기), 녹화 목록(시간, 길이, 메모). Claude가 가져갔는지 표시. 지우기.
5. **설정**: 단축키(고르기 Ctrl+Shift+G, 녹화 Ctrl+Shift+R) 바꾸기, Windows 시작 시 자동 켜기, 녹화 화질/최대 길이, 데이터 폴더 위치, Claude MCP 연결 안내(명령 한 줄 복사).

## 상태 (빠짐없이)
- 빈 상태: 등록된 앱 0개 → 첫 등록 안내.
- 로딩: 사전 만드는 중(진행).
- 오류: 소스 폴더 없음, 사전 0개(이 폴더엔 id가 없음 → 이유와 해결 안내).
- 정상.

## 공통 조건
- 데스크톱 창 960×640 기준(작게 줄였을 때 720×520도 깨지지 않게).
- 모든 글자 한국어. 용어는 쉬운 말(예: "사전" = 부품 이름표 목록).
- 키보드만으로 다 쓸 수 있게, 포커스 링 보이게. 모션 줄이기 존중.
- 브랜드 색: 주황 #ff6a00 (트레이 아이콘). 녹화 빨강 #e5534b.
- 결과: HTML 한 파일(외부 CDN 금지, 인라인 CSS/JS). 탭/화면 전환·등록 3단계·빈/로딩/오류 상태를 실제로 눌러 볼 수 있게.
