⚙️ 가운데: MCP 두 개를 같이 연결

Windows-MCP (설치됨 · 그대로 씀)

App 앱 실행·창 전환 · Snapshot 부품 트리 읽기 · Screenshot(region) 수정 후 다시 찍기
Click · Type · WaitFor 고친 뒤 같은 화면·상태까지 AI가 다시 이동
→ 원래 계획의 capture(target)는 만들 필요 없음

UI 이름표 MCP (직접 · 작게)

build_catalog(project) 사전 만들기
get_picks() 내가 고른 것 + 메모 + 캡처 가져오기
catalog_lookup(id 또는 이름) AutomationId·이름 → 파일:줄
